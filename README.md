# Html4View
A simple Android View which support part of HTML4.0+CSS1.0

Add to `build.gradle`:
```
dependencies {
  implementation 'androidx.appcompat:appcompat:1.7.1'
  implementation 'com.google.re2j:re2j:1.7'
  implementation 'org.jsoup:jsoup:1.22.1'
}
```
